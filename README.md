# 📄 Doc2MD Pro

Doc2MD Pro is a lightning-fast, offline-capable Windows application that instantly converts your PDFs, Word Documents, Excel sheets, and PowerPoints into clean Markdown (`.md`) files.

Built with Python and a sleek, modern UI, it offers both a secure offline mode and a free, AI-enhanced mode (powered by Google Gemini) to fix complex formatting and read images inside your documents.

## ✨ Features
* **100% Free & Open Source:** No subscriptions, no hidden fees.
* **Drag-and-Drop Batch Processing:** Convert dozens of files at once.
* **Hybrid AI Technology:** * **Offline Mode:** Extracts text instantly using your local CPU (Secure & Private).
  * **AI Mode (Free):** Connects to Google's Gemini 1.5/2.5 Flash to perfectly structure headers, fix OCR errors, and describe images.
* **Modern UI:** Built with CustomTkinter for a beautiful, responsive dark-mode experience.

## 🚀 How to Install (Windows)
You do **not** need Python or the terminal to use this app.
1. Go to the [Releases page](../../releases/latest).
2. Download `Doc2MD_Setup.exe`.
3. Double-click the installer to safely install it on your PC!

## 🧠 Getting a Free AI Key
To use the AI-enhanced mode, you just need a free API key:
1. Open the app and toggle **Enable AI Mode**.
2. Click the blue link to visit Google AI Studio.
3. Click "Create API Key", copy it, and paste it into the app. It's instantly ready!
